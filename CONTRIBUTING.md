# Contributing

- run `npm test` before a pull request, Node 22 or newer, after `npm i --no-save --omit=optional @anthropic-ai/claude-agent-sdk@0.3.258` so the live parity test runs as it does in CI
- one source file per language, no code comments, names carry the meaning
- deletions beat additions, and a new file needs a reason the README can state
- keep the dead-ends table current when you learn why something fails
- claims about macOS or Claude behavior come with the Claude Code and SDK versions you verified
